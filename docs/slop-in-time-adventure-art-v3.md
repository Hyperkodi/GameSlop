# Slop in Time — adventure and boss artwork v3

Generated with the built-in imagegen tool. Final workspace assets:

- `games/slop-in-time/skin/gameslop/combat-v3.png`: dedicated guard, jab, windup, uppercut, jump, airborne kick, throw and weapon poses. Combat uses whole-character frames instead of an arm drawn over the abdomen. The third source pose is retained as a windup reference; the game combines guard/jab timing with recoil for its cross.
- `games/slop-in-time/skin/gameslop/flyers-v3.png`: six distinct aerial enemies.
- `games/slop-in-time/skin/gameslop/bosses-v3.png`: twelve boss sprites, two poses for each of six original designs. A runtime red palette preserves shading below 30% health.

The initial boss sheet used a gradient backdrop. It was revised to a white matte for runtime extraction; only the final white version is used. Characters retain the established 16-bit visual treatment. Route floors, traps, throwable covers and weapons are native Canvas artwork.
