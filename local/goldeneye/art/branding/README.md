# GoldenEye 64 / SLOP

The shared logo uses formal gold GOLDENEYE 64 lettering with a red paintbrush
SLOP overlay across EYE. The launcher and toolbar use branding.css; the native
N64 title uses the same overlay composited by mods/branding/pack.js.

Artwork: slop-brush.png. Generated using the built-in image generation tool,
with its transparent alpha preserved.

Final prompt:

Use case: logo-brand. Create a production transparent PNG overlay for a game logo. The ONLY text is exactly "SLOP", four uppercase letters S L O P, very readable. It looks hastily graffitied with a broad real paintbrush: bold vermilion-red paint, ragged bristle edges, dry-brush gaps, thick expressive uneven strokes, a few small paint flecks and two short drips. Slight upward energy, compact wide word, roughly 2.4:1 word proportions. No outline, no shadow, no other text or graphics. Center the entire word with tight but safe transparent margins in a wide landscape canvas. Genuine transparent background with alpha, no checkerboard or colored background. This will be pasted across the Eye in GoldenEye 64, so it must feel like fresh red brush paint vandalizing formal gold lettering.
